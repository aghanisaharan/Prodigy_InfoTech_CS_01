# Caesar Cipher Tool

This repository contains my Python program for Task 01 of the Cyber Security Internship at **Prodigy InfoTech**. 

The objective of this project is to implement the Caesar Cipher algorithm, allowing users to input a message and a shift value to perform encryption and decryption.

## Features
* **Alphabetic Processing:** Encrypts and decrypts alphabetic characters by shifting them across the alphabet.
* **Numeric Handling:** Handles numeric digits by shifting them individually within the 0-9 range.
* **Format Preservation:** Preserves spaces and punctuation symbols to maintain the structure and readability of the original message.

## Requirements
* Python 3.x
